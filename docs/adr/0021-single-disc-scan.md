# One disc scan — makemkvcon always, no fast scan

Supersedes ADR 0002 (fast scan with escalation). Every video disc takes `makemkvcon info` (ADR 0020's selection table made this the right trade): the table's size column needs sizes, and the fast scan yielded durations only — TV size cells would always be blank, and the rip paid for that gap later with the duration-join rename matching staged files back to scanner titles. With one scan, MakeMKV title numbers are always real (sub-floor titles included), the escalation ladder — fail, ±1s duplicates, menu runs — is deleted along with the lsdvd/ffprobe paths, and one scan implementation exists instead of two plus a bridge. Cost: roughly one to two minutes more per TV disc before the table appears, spent while the operator reads the table anyway. DVDs stay key-free; the MakeMKV key still gates BD only. CDs are untouched — cyanrip's TOC pre-pass is not a disc scan.
